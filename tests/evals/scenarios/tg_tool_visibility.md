# Telegram Tool Visibility

## Steps
1. Send: "List the files in my .claude/skills directory and tell me how many skills I have"
   Wait: 90

## Criteria
- The bot sent at least 2 messages total (one status message showing tool activity, one with the actual response)
- The response mentions specific skill names or a count of skills
- The response is not a refusal or error message
- At least one message from the bot shows evidence of tool activity (contains words like "Read", "Grep", "Glob", "Bash", "thinking", or similar tool/status indicators)
