# Research

Research conducted during the OBS Agent design phase. Each file summarizes findings from investigating reference implementations and tools.

## Reference Implementations

- [[Agent/system/research/openclaw|OpenClaw]] - Personal AI assistant with memory, multi-channel, skills. Largest reference project. Key areas: memory system, session persistence, skill/instruction system, prompts.
- [[Agent/system/research/claude-mem|claude-mem]] - Memory observer pattern, knowledge extraction, lifecycle hooks, mode-based configuration.
- [[Agent/system/research/claude-sdk|Claude Agent SDK for Python]] - SDK API reference: sessions, hooks, MCP tools, subagents, forking.

## Origin

Research was conducted by sub-agents during the [[Agent/system/sessions/2026-02-11-initial-design|initial design session]]. Sub-agent session transcripts are linked from each research file.
